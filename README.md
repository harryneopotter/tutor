# 🎓 Tutor Virtual Classroom

**A simple, private app to manage your tutoring schedule and student information.**

> 📱 Works on iPhone, iPad, Android, and Computer  
> 🔒 100% Private - Your data stays on YOUR device only  
> ✈️ Works offline - No internet needed after setup

---

## 📖 What Is This App?

**Tutor Virtual Classroom** is like a digital planner designed specifically for tutors and teachers. It helps you:
- Track your class schedule
- Store student information and notes
- Manage lesson plans and curriculum
- Handle cancellations and waitlists
- Export your data for backup

Everything stays on your device - **no cloud, no login, completely private.**

---

## 🎯 Who Is This For?

✅ Private tutors managing 1-on-1 sessions  
✅ Teachers organizing small group classes  
✅ Anyone who values privacy and wants their data local  
✅ Users who need offline access (no internet required)

## 🚀 Quick Start Guide

### **First Time Setup**

1. **Open the app** in your web browser (Chrome, Safari, Firefox, or Edge)
2. Click **"Load Sample Data"** to see how it works (optional - you can skip this)
3. Click **"+ Add Student"** to add your first real student
4. Start scheduling classes!

### **Daily Use**

1. **View Today's Schedule**: Click **"Today"** tab to see what's coming up
2. **Add a Class**: Go to **"Weekly Calendar"** → Click any time slot → Fill in details
3. **Manage Students**: Click **"Binder"** → Select student → Add notes, lesson plans, etc.
4. **Handle Cancellations**: Long-press any class to cancel and find a replacement

## 📱 Main Features Explained

### 1️⃣ **Weekly Calendar** 📅
**What it does:** Shows your entire week at a glance  
**How to use it:**
- Click any empty time slot to schedule a new class
- Click an existing class to view/edit details

## 💾 Data & Privacy Explained

### **Where is my data stored?**
Your data is stored **only on your device** in your browser's storage (called "IndexedDB"). It's like saving a document on your computer - it never goes to the internet.

### **Is it safe?**
✅ Yes! Your data:
- Never leaves your device
- Doesn't sync to any cloud
- Can't be seen by anyone else
- Is protected by your browser's security

### **Important Things to Know:**

1. **Data is tied to your browser**
   - Chrome data ≠ Firefox data
   - Personal Chrome profile ≠ Work Chrome profile
   - Laptop ≠ Phone

2. **Data doesn't sync automatically**
   - If you use multiple devices, you need to manually backup and restore

3. **Backup regularly!**
   - Go to Settings → "Backup All Data" 
   - Save the file somewhere safe (like Google Drive or USB stick)
   - If you clear browser data or switch devices, you'll need this file

4. **To use on multiple devices:**
   - Device 1: Settings → Backup All Data → Save file
   - Transfer file to Device 2 (email, USB, etc.)
   - Device 2: Settings → Restore from Backup → Select file

## 🆘 Common Questions

### **Q: I cleared my browser data and lost everything. Can I get it back?**
A: Only if you made a backup! Always backup regularly (Settings → Backup All Data).

### **Q: Can I use this on multiple devices?**
A: Yes, but data doesn't sync automatically. Use Backup/Restore to transfer.

### **Q: Does this need internet?**
A: Only for the first setup. After that, it works 100% offline.

### **Q: Can other people see my data?**
A: No! It's completely private and stored only on your device.

### **Q: What if I switch browsers?**
A: Use Backup on the old browser, then Restore on the new browser.

### **Q: How do I delete a student?**
A: Currently, students can only be archived (not permanently deleted). This prevents accidental data loss.

### **Q: Can I print my schedule?**
A: Yes! Use your browser's Print function (Ctrl+P or Cmd+P).

### **Q: I made a mistake. Can I undo?**
A: Some changes can be undone (e.g., canceling a class). For major mistakes, restore from a recent backup.

## 🔧 Technical Information (For Developers)

### Tech Stack
- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Styled Components (Liquid Glass theme)
- **State**: Zustand (modular slices)
- **Database**: Dexie.js (IndexedDB)
- **Testing**: Vitest + Playwright + Axe (a11y)

### Local Development
```bash
npm install      # Install dependencies
npm run dev     # Start dev server
npm run build   # Build for production
npm test        # Run tests
```

### Architecture
```
src/
├── features/   # Domain features (calendar, binder, etc.)
├── ui/         # Reusable components (Button, Card, Modal)
├── store/      # State management (Zustand slices)
├── db/         # Database schema and repositories
└── utils/      # Helpers (validation, backup, etc.)
```

### Key Features
- ✅ PWA-ready (offline-first)
- ✅ Type-safe (TypeScript)
- ✅ Accessible (WCAG 2.1 AA compliant)
- ✅ No external dependencies for data
- ✅ Full data export (JSON + ZIP)
